description: List every moonlet you own
---

Call the `moonlets_list_my_roster` tool from the `moonlets` MCP server.

Render the roster as a compact list, one moonlet per line:

- Format: `<species name> (Lv. N · <rarity>)` with a marker — `▶` or similar — next to the active one
- Group implicit by leaving them in caught-at order from the tool
- If the roster is empty, tell the user to choose a starter at the dashboard

No long preamble — go straight to the list.
